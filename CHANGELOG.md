# Changelog — GatherHud (édition Ebonhold)

## v1.2.0 — 2026-10-20
- Les textes ajoutés pour l'édition Ebonhold (option « Masquer l'icône minimap » et infobulle de l'icône) passent par la table de traduction : anglais par défaut, français sur un client frFR. Ils n'étaient affichés qu'en français, quelle que soit la langue du client.
- Une seule ligne `## Version` dans le `.toc` (il y en avait deux : `1.1.6` et `v1.1.6`).
- Numérotation : 1.2.0 succède à 1.1.6-fr1, avec un numéro strictement supérieur pour que les outils de mise à jour le reconnaissent comme plus récent.

*English*
- The strings added for the Ebonhold edition ("Hide minimap icon" option and the minimap icon tooltip) now go through the locale table: English by default, French on a frFR client. They used to be shown in French regardless of the client language.
- A single `## Version` line in the `.toc` (there were two: `1.1.6` and `v1.1.6`).
- Numbering: 1.2.0 follows 1.1.6-fr1 with a strictly higher number so that update tools see it as newer.

## v1.1.6-fr1 — 2026-06-25
- Traduction française complétée (options d'angle de caméra).
- Icône sur la minimap : clic gauche pour les options, clic droit pour activer/désactiver le HUD, option pour la masquer.
- Bibliothèques embarquées (LibStub, CallbackHandler-1.0, LibDataBroker-1.1, LibDBIcon-1.0).

*English*
- Completed French translation (camera angle options).
- Minimap icon: left-click opens the options, right-click toggles the HUD, option to hide it.
- Embedded libraries (LibStub, CallbackHandler-1.0, LibDataBroker-1.1, LibDBIcon-1.0).
